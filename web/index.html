WHAT THIS IS / IS NOT

  • An uncontained organism at a fixed tissue temperature — the Q1 model. Net carbon is light in, respiration out; nothing holds it together.
  • No pressure vessel. Liquid water cannot exist in vacuum at these temperatures; the vessel that would contain it is unbuilt, and it is a precondition of the modelling line, not a later extension.
  • No spectral wall. A scalar attenuation coefficient k for a wall was shown to be a category error (Q3): the wall's PAR attenuation is spectral across a factor of ~701, so one number cannot stand for it.
  • The registered thermal predictions were falsified (Q2b): carbon was predicted to bind, and temperature binds instead — for the algal class, the only class the run answered. The gate that excluded the vascular class has since been retired as uninformative, and running the same code on vascular gives carbon as the binding limit at Ω = 25 and 30, where the prediction would have held. The falsification stands for algal; whether it generalises is open (see FINDINGS).
  • The hatched bands are predictions written before the run, not results. For the algal class the prediction failed.

Repository

The browser model (web/model.js) is a port of sim/physiology.py, sim/thermal.py, sim/organism.py and sim/vessel.py. It is pinned to the Python model by web/fixtures.json through tests/test_parity_js.py, and its crossover values are checked against the committed experiments/q1_crossover/crossover.csv.
