# Plans

Step-by-step execution checklists, one per registered question, written before
the code and kept afterwards as a design record — the companion to the specs in
`../specs/`, which say _what_ to build and why, where these say _in what order_.

They are working documents, not documentation: they record the order the work was
actually taken in, including the dead ends. Nothing here is authoritative about a
result — `docs/FINDINGS.md` is.

The tool and command names in them (`superpowers:*`, skill names, subagent
dispatches) are the author's own private tooling. They are not part of this
repository, are not needed to run or reproduce anything, and will not resolve
for a reader. `README.md` under "Run it" has the commands that do.
