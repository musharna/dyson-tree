## Scope allowlist — read twice

You MAY: port the existing functions to JS for display, build the page, write docs, add
fixtures and tests, add LICENSE/CITATION/CHANGELOG/workflow. You MAY NOT: build the
pressure vessel, add a spectral wall, add any input the Python model does not already
take, change any preset or constant, run a new sweep, or register a new question.
**Wall thickness is NOT an input** — the vessel is unbuilt and scalar attenuation is the
known category error. If a step seems to need a forbidden action, STOP and hand back.

## Stages, in order. Each has an observable "done".

### 1. Branch, baseline, fixtures FIRST

- `git switch -c release/1.0-rc` from `1d9cea5`. `python -m pytest -q` → record in
  `docs/RELEASE-1.0.md` (create it; every stage appends evidence there).
- `tools/make_fixtures.py` → `web/fixtures.json`, generated by the **Python** model at
  this commit (record `git rev-parse HEAD` inside the file). Contents, per preset in
  `PRESETS` and per `k` in the Q1 prereg's swept values (read them from
  `experiments/q1_crossover/prereg.yaml`, do not retype):
  - `net_carbon(r)` on a fixed grid `r ∈ linspace(0.5, 100, 400)` AU;
  - `equilibrium_temperature` on the same grid;
  - `crossover_distance_for(org, k, n_grid=<prereg value>)`, or `null` if no root;
  - `compensation_irradiance`;
  - three edge cases chosen from the model's own domain: a preset/`k` pair with no
    crossover inside `[0.5, 100]`; `r_d` at the `ValueError` boundary
    (`leaf respiration >= a_max`); the algal `t_min` floor.
- Per-quantity tolerances declared IN the fixture file: `abs_err ≤ atol + rtol·|ref|`
  with `rtol = 1e-9` for closed-form quantities (irradiance, gross, respiration, T_eq,
  compensation) and `rtol = 1e-6`, `atol = 1e-6 AU` for `crossover` (bracketed root —
  the JS root-finder will not be `brentq`). If any tolerance has to be loosened later,
  the reason is written next to it; the number is never silently changed.
- DONE when: fixtures exist, are generated by a committed script, and carry the SHA.

### 2. JS port — `web/model.js`, pure functions only, no DOM

- Port `physiology.py`, `thermal.py`, and the parts of `organism.py` the displayed
  outputs use (`Organism` as a plain object + `leaf_respiration`, `net_carbon`,
  `net_carbon_at_equilibrium`, `compensation_irradiance`, `crossover_distance_for`;
  presets copied verbatim with a comment naming the Python line). Own root-finder
  (bisection on the same bracketing grid is fine; document it).
- `tests/test_parity_js.py`: runs `node web/parity.mjs` which loads `fixtures.json`,
  evaluates every case, and prints a JSON report; the Python test asserts every
  quantity within its declared tolerance AND that the `null`-crossover cases are
  `null` in JS too. This test **must be seen to fail**: temporarily break one constant
  in `model.js`, run, confirm the failure names that quantity, restore. Record the
  mutant + its failure line.
- DONE when: parity green, mutant seen to fail, both recorded.

### 3. The page — `web/index.html` + `web/app.js`, no build step, no CDN

- Inputs: preset (`vascular` / `algal`), distance `r` (slider, 0.5–100 AU, log scale),
  `k` (select from the Q1 swept values only). Nothing else.
- Outputs: net-carbon-vs-distance curve for the selected preset/`k` with the current `r`
  marked; the crossover distance (or "no crossover in range"); `T_eq(r)`; the
  compensation irradiance. Plain SVG or canvas drawn by hand — no library.
- **Overlays, labelled exactly**: the Q1 registered bands drawn as hatched ranges with
  the legend text `pre-registered band (Q1) — vascular: HELD · algal: FAILED`; the
  measured Q1 crossovers as points labelled `model output`. Never draw a falsified band
  in the same style as a result.
- A fixed "What this is / is not" panel beside the plot (not in a tooltip, not only in
  FINDINGS): _uncontained organism at fixed tissue temperature; no pressure vessel; no
  spectral wall — a scalar attenuation was shown to be a category error (Q3); the
  registered thermal predictions were falsified (Q2b) — see FINDINGS._ Links to
  FINDINGS and the repo.
- Copy `web/` to `site/` via `tools/build_site.sh` (adds `.nojekyll`); the page must
  work from `file://` and from a subpath (`https://musharna.github.io/dyson-tree/`)
  — use relative URLs only.
- Headless smoke (Playwright via `npx playwright` is acceptable; or Python
  `playwright`): HTTP 200, zero console errors, moving the slider changes the marked
  value, both presets render, the crossover label matches the fixture value for the
  default selection to the declared tolerance. Record.
- DONE when: clean-checkout proof (`git clone --depth=1 file://$PWD /tmp/dt-verify &&
cd /tmp/dt-verify && tools/build_site.sh && test -f site/index.html && test -f
site/.nojekyll`) and the smoke pass.
